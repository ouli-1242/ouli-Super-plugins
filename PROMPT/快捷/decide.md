# 抉择

为一个真实决策选一条路。不为凑数列选项，不挑无关痛痒的判据。

1. **选项**：列出实际可选的路线；排除明显劣于他项的，并说明为何排除。
2. **判据**：影响结论的维度，按重要性排序。
3. **取舍**：每个选项在各判据上的表现与代价；只列实质差异。
4. **最便宜的消歧实验**：哪个判据信息最缺、最关键？用最低成本补它——而不是在信息不足时硬推推荐。
5. **推荐与触发条件**：推荐哪个；在什么前提下该改选另一个。

判据必须互相独立：若某条会连带决定另一条，只保留更上游的那条。
不要为了显得全面而拆分或硬凑。
无明显优势就直说"无显著差异，按 X 偏好选"。
信息不足以推荐就直说"先做最便宜实验：Y"，不强行推荐。
