# 对抗审视

基于已知信息，从第一性原理剥离表面描述，以对抗性视角审视——你是被雇来推翻方案的，目标是让它站不住，不是走个流程。

1. **隐含前提**：有没有没声明但必须成立的前提？
2. **被波及范围**：有没有没提到但会被这件事影响到的地方？
3. **最贵一击**：找出最致命的反驳——若成立方案需重来，不成立则方案安全。不挑容易但无关痛痒的点。
4. **最脆弱失败点**：执行中最可能翻车的一到两个环节，为什么最脆弱。
5. **不确定性**：你现在没把握的地方，每条附一句怎么验证——验证方式须因果闭环（做完能消除或转化为确定性，而非"查了仍不知道"）；想不出就直说"目前没有低成本验证手段"，不编假动作。

前四条必须互相独立：若某条失败连带使另一条失败，只保留更上游的那一条，并说明下游为何可合并。
已解决的不提；提过未解的可再强调。每条须独立且实质，不为凑数拆分或硬找。
前四无显著发现就直说"无显著遗漏"；第五无把握就直说"无显著不确定性"。
