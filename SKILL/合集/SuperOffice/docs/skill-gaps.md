# Skill 缺口日志

喂养新 skill 立项纪律的观察日志。**没有观察到失败，就不写新 skill**——真实的失败累积在这里，直到够格立项。（SuperOffice 不带 writing-skills skill，规则由本文件承载。）

## 规则

真实会话一旦撞上"没有现成动词覆盖这个任务"，当场记一行。每次出现记一行，任务描述要具体（不要泛化）。**同一缺口出现 3 次独立 occurrence = 失败可观察、可复现 = 新 skill 提案成立。**

记住本包的架构：动词层是有意有限的。提议新动词之前，先判断缺口是不是缺一份**资产**（doc-asset profile）——专门化长在资产里，不长在新动词里。
